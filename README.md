
# Student Event Management System

## Project Description
A website for students to view college events
and register for different events.

## Technologies
- HTML
- CSS
- JavaScript
- Git and GitHub

## Branching Strategy

1. main:
   Contains stable project code.

2. feature/home-page:
   Developer 1 works on the home page.

3. feature/register-event:
   Developer 2 works on event registration.

4. feature/cancel-event:
   Developer 3 works on cancellation.

## Git Workflow
- Create a feature branch.
- Develop the feature.
- Add and commit changes.
- Merge the feature into main.
- Resolve merge conflicts if they occur.
